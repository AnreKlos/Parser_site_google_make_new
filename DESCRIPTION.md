# KURSOR PARSER — Описание системы

## Назначение

**KURSOR PARSER** — комплексная система для извлечения и анализа данных с веб-сайтов. Проект объединяет два функциональных модуля:

1. **Универсальный парсер с GUI** — извлечение структурированных данных (цены, контакты, услуги)
2. **Site Audit Parser** — аудит веб-сайтов и сбор бизнес-лидов

---

## Модуль 1: Универсальный парсер сайтов

### Назначение

Автоматизированное извлечение структурированных данных с веб-сайтов бизнеса с помощью графического интерфейса, автоматического определения селекторов и LLM-интеграции.

### Ключевые возможности

| Функция | Описание |
|---------|----------|
| GUI на PySide6 | Удобные вкладки для управления процессом |
| Автоопределение | Анализ HTML-структуры для поиска цен, контактов, услуг |
| LLM-интеграция | OpenRouter API для точного извлечения данных |
| JavaScript | Рендеринг динамических страниц через Playwright |
| Конфигурации | Селекторы сохраняются для каждого домена |
| Экспорт | Markdown и JSON форматы |
| Генерация лендингов | Автоматическое создание сайта-визитки |

### Извлекаемые данные

- **Цены и тарифы** — таблицы цен, прайс-листы
- **Контакты** — телефоны, email, адреса, соцсети
- **Услуги/товары** — названия, описания, характеристики

### Запуск

```bash
# GUI режим
python scraper_gui.py

# Консольный режим
python scraper_core.py <url> [--output <путь>] [--force-llm] [--use-js]
```

### Ключевые модули

| Файл | Назначение |
|------|------------|
| `scraper_gui.py` | Графический интерфейс (PySide6) |
| `scraper_core.py` | Ядро парсинга, функция `run_parse()` |
| `auto_detector.py` | Автоматическое определение селекторов |
| `llm_engine.py` | Интеграция с OpenRouter API |
| `config_manager.py` | Управление конфигурациями |
| `site_generator/` | Генерация лендингов |

## Модуль 2: Site Audit Parser (site-audit-v1/)

### Назначение

Автоматический аудит веб-сайтов для оценки технического состояния, выявления устаревшего дизайна и сбора бизнес-лидов из внешних источников.

### Ключевые возможности

| Функция | Описание |
|---------|----------|
| Tech score | Оценка технического состояния (0-100) |
| Old score | Оценка устаревания дизайна (0-100) |
| Lead priority | Приоритет лида (0-100) |
| Сбор лидов | Яндекс Карты, 2GIS |
| Экспорт | CSV (UTF-8 BOM) и SQLite |

### Классификация качества сайтов

| Метка | Условие | Рекомендация |
|-------|---------|--------------|
| `strong` | tech ≥ 80 и old ≤ 20 | Отличный сайт |
| `average` | 50 ≤ tech < 80 | Требует доработки |
| `weak` | tech < 50 или old > 40 | Требует редизайна |

### Классификация лидов

| Метка | Priority | Действие |
|-------|----------|----------|
| `hot` | ≥ 75 | Высокий приоритет |
| `target` | 55-74 | Хороший потенциал |
| `review` | 40-54 | Требует анализа |
| `ignore` | < 40 | Не подходит |

### Запуск

```bash
cd site-audit-v1

# Сбор лидов из Яндекс Карт
python -m src.main --source yandex_maps --query "стоматология" --city "Казань" --limit 30

# Пакетный аудит
python -m src.main --batch data/sites.txt

# Один URL
python -m src.main --url https://example.com
```

### Ключевые компоненты

| Компонент | Назначение |
|-----------|------------|
| `SiteChecker` | Проверка доступности сайта |
| `HtmlAnalyzer` | Анализ HTML-контента |
| `Scorer` | Вычисление оценок |
| `YandexParser` | Парсер Яндекс Карты |
| `TwoGISParser` | Парсер 2GIS |
| `CsvExporter` | Экспорт в CSV |
| `SQLiteExporter` | Экспорт в SQLite |

## Конфигурация

### Переменные окружения (.env)

```bash
# LLM (OpenRouter)
OPENROUTER_API_KEY=your_key

# Playwright
HEADLESS=true
TIMEOUT_MS=30000

# Яндекс Карты (site-audit-v1)
YANDEX_MAPS_API_KEY=your_key
YANDEX_MAPS_ENABLED=true

# Паузы между запросами
MIN_PAUSE_SEC=2.0
MAX_PAUSE_SEC=5.0
```

## Процесс работы

### Парсер (pipeline)

1. **Загрузка HTML** — requests или Playwright
2. **Автоопределение** — анализ структуры, поиск селекторов
3. **Оценка** — расчёт score (0.0-1.0)
4. **LLM уточнение** — если score < 0.75
5. **Сохранение конфига** — для повторного использования
6. **Извлечение данных** — применение селекторов
7. **Экспорт** — Markdown + JSON

### Аудит (pipeline)

1. **Ввод** — список URL или параметры поиска
2. **Проверка** — доступность, редиректы, SSL
3. **Анализ** — HTML-контент, метаданные
4. **Оценка** — технический и эстетический баллы
5. **Классификация** — strong/average/weak
6. **Экспорт** — CSV + SQLite

## Устранение неполадок

### OPENROUTER_API_KEY not set
Добавьте ключ в `.env` или используйте только автоопределение.

### Playwright timeout
Увеличьте `TIMEOUT_MS` или проверьте сеть. Установите: `playwright install chromium`.

### Пустые результаты
- Проверьте JavaScript-контент (`--use-js`)
- Увеличьте задержку между запросами
- Проверьте селекторы

### YANDEX_MAPS_API_KEY не настроен
Получите ключ на [Яндекс.Разработчик](https://developer.tech.yandex.ru/) и добавьте в `.env`.

### Limit is exceeded (403)
Превышена квота Яндекс API. Увеличьте паузы или дождитесь сброса.

## Расширение

### Новый тип данных (парсер)

1. Добавьте функцию в `auto_detector.py`
2. Обновите промпты в `llm_engine.py`
3. Добавьте нормализацию в `scraper_core.py`

### Новый парсер (site-audit-v1)

1. Создайте файл в `src/parsers/`
2. Реализуйте метод `search(query, city, limit)`
3. Добавьте условие в `LeadCollector`

### Новый шаблон лендинга

Добавьте папку с шаблоном в `site_generator/templates/`.

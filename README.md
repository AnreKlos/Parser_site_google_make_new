# 🌐 KURSOR PARSER — Универсальный парсер сайтов

**KURSOR PARSER** — комплексная система для извлечения и анализа данных с веб-сайтов, состоящая из двух модулей: универсального парсера с GUI и системы аудита сайтов.

---

## 📦 Состав проекта

### 1. Универсальный парсер сайтов с GUI и LLM

Современный инструмент для извлечения данных с веб-сайтов с графическим интерфейсом, автоматическим определением селекторов и интеграцией с OpenRouter API.

**Возможности:**
- 🖥️ **Графический интерфейс** на PySide6 с удобными вкладками
- 🔍 **Автоматическое определение селекторов** — анализ структуры страницы
- 🤖 **LLM-интеграция** — использование OpenRouter API для сложных случаев
- ⚡ **Поддержка JavaScript** — рендеринг динамических страниц через Playwright
- 💾 **Экспорт данных** — Markdown и JSON форматы
- 🌐 **Генерация лендингов** — автоматическое создание сайта на основе данных

### 2. Site Audit Parser v1 (site-audit-v1/)

Система автоматического аудита веб-сайтов для оценки технического состояния и сбора бизнес-лидов.

**Возможности:**
- 📊 **Оценка технического состояния** (Tech score): доступность, HTTPS, валидность HTML
- 🎨 **Оценка устаревания дизайна** (Old score): эстетические признаки
- 🎯 **Приоритизация лидов** (Priority): комплексная оценка качества сайта
- 📋 **Сбор лидов из внешних источников**: Яндекс Карты, 2GIS
- 📁 **Экспорт в CSV и SQLite**

## 📋 Использование

### Графический интерфейс парсера

1. **Введите URL** сайта в поле вверху
2. **Нажмите "Автоопределение"** — программа проанализирует страницу
3. **Перейдите на вкладку "Селекторы"** — при необходимости отредактируйте
4. **Нажмите "Запустить"** — извлечь данные
5. **Генерация лендинга** — автоматически создастся сайт-визитка

### Консольный режим парсера

```bash
python scraper_core.py <url> [--output <путь>] [--force-llm] [--use-js] [--no-json]
```

**Параметры:**
| Параметр | Описание |
|----------|----------|
| `url` | Адрес сайта (обязательно) |
| `--output` | Путь для сохранения (по умолчанию: `data/domain.md`) |
| `--force-llm` | Принудительно использовать LLM |
| `--use-js` | Использовать Playwright для JavaScript-рендеринга |
| `--auto-detect-only` | Только определить селекторы |
| `--no-json` | Не сохранять JSON |

### Сбор лидов (site-audit-v1)

```bash
# Из Яндекс Карт
python -m src.main --source yandex_maps --query "стоматология" --city "Казань" --limit 30

# Из 2GIS
python -m src.main --source 2gis --query "автосервис" --city "Москва" --limit 50

# Пакетная обработка
python -m src.main --batch data/sites.txt
```

## ⚙️ Настройка

### Переменные окружения

Создайте файл `.env` в корне проекта:

```bash
# OpenRouter API ключ (для LLM)
OPENROUTER_API_KEY=your_api_key_here

# Настройки Playwright
HEADLESS=true
TIMEOUT_MS=30000

# API ключ Яндекс Карт (для site-audit-v1)
YANDEX_MAPS_API_KEY=your_key_here
YANDEX_MAPS_ENABLED=true
```

### Конфигурационные файлы

Конфигурации парсера хранятся в `configs/domain.json`:

```json
{
  "selectors": {
    "price": ".price-table",
    "contact": {
      "phones": ".phone",
      "emails": ".email",
      "address": ".address"
    },
    "service": ".service-item"
  },
  "score": 0.85
}
```

## 🔍 Как работает парсер

### Процесс извлечения данных

1. **Загрузка HTML** — через requests или Playwright
2. **Автоопределение** — анализ структуры для поиска цен, контактов, услуг
3. **Оценка уверенности** — score от 0.0 до 1.0
4. **LLM уточнение** — если score < 0.75, используется OpenRouter API
5. **Сохранение конфига** — селекторы сохраняются для домена
6. **Извлечение данных** — применение селекторов
7. **Экспорт** — сохранение в Markdown и JSON

### Автоматическое определение

Алгоритм ищет:
- **Цены**: таблицы, блоки с классами `price`, `cost`, `tarif`
- **Контакты**: футеры, блоки `contact`, `footer`, `social`
- **Услуги**: карточки `service`, `product`, `card`, `item`

## 🐛 Устранение неполадок

### Ошибка: "OPENROUTER_API_KEY not set"
LLM функции отключены. Добавьте ключ в `.env`.

### Ошибка: "Playwright timeout"
Увеличьте `TIMEOUT_MS` или используйте `--use-js`.

### Пустые результаты
- Проверьте, не загружается ли контент через JavaScript
- Используйте флаг `--use-js`
- Проверьте селекторы во вкладке "Селекторы"

### Медленная работа
- Установите `lxml`: `pip install lxml`
- Отключите LLM для доменов с высоким score

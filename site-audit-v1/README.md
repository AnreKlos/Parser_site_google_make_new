# Site Audit Parser v1

> **Статус:** автономный модуль. Запускается отдельно от основного
> проекта (`python -m src.main ...`). Не интегрирован в общую БД и
> пайплайн, но сохраняется как рабочий CLI-инструмент для сбора
> лидов и аудита сайтов.

Система автоматического аудита веб-сайтов для оценки технического состояния и потенциальных лидов с возможностью сбора контактов из внешних источников.

## Обзор

Site Audit Parser v1 — это инструмент для автоматического анализа веб-сайтов и сбора бизнес-лидов, который оценивает:

- **Техническое состояние** (Tech score): доступность, HTTPS, валидность HTML, наличие viewport, форм
- **Устаревание дизайна** (Old score): эстетические признаки, устаревшие паттерны
- **Приоритет лида** (Priority): комплексная оценка от 0 до 100
- **Качество страницы** (Quality): strong/average/weak на основе технических и эстетических метрик

### Ключевые возможности

- **Сбор лидов из внешних источников**: 2GIS, Яндекс Карты
- **Пакетная обработка URL** из файла
- **Подробный консольный вывод** на русском языке
- **Экспорт результатов** в CSV (UTF-8 BOM) и SQLite
- **Обработка ошибок** SSL и недоступных сайтов
- **Прогресс-бар** с помощью tqdm
- **Настраиваемая задержка** между запросами

### Поток данных

#### Режим 1: Аудит сайтов из файла
1. **Ввод**: Список URL из файла или аргумента `--batch`/`--url`
2. **Проверка**: `SiteChecker` получает HTML и метаданные (статус, редиректы, SSL)
3. **Анализ**: `HtmlAnalyzer` извлекает title, h1, viewport, формы, телефоны
4. **Оценка**: `Scorer` вычисляет технический и эстетический баллы
5. **Экспорт**: `CsvExporter` и `SQLiteExporter` сохраняют результаты
6. **Вывод**: Консольный отчет на русском языке

#### Режим 2: Сбор лидов из внешних источников
1. **Ввод**: Параметры поиска (`--source`, `--query`, `--city`, `--limit`)
2. **Сбор**: `LeadCollector` использует соответствующий парсер (`YandexParser` или `TwoGISParser`)
3. **Результат**: Список `BusinessRecord` с контактами и ссылками на карточки
4. **Аудит** (опционально): Автоматический аудит сайтов найденных лидов
5. **Экспорт**: Сохранение в CSV и SQLite

## Установка

### Требования
- Python 3.10+
- pip

### Шаги установки

1. Клонируйте репозиторий:
```bash
cd site-audit-v1
```

2. Создайте виртуальное окружение (рекомендуется):
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Настройте переменные окружения (опционально):
```bash
cp .env.example .env
# Отредактируйте .env при необходимости
```

## Использование

### Базовые команды

**Сбор лидов из Яндекс Карт:**
```bash
python -m src.main --source yandex_maps --query "стоматология" --city "Казань" --limit 30
```

**Сбор лидов из 2GIS:**
```bash
python -m src.main --source 2gis --query "автосервис" --city "Москва" --limit 50
```

**Пакетная обработка из файла:**
```bash
python -m src.main --batch data/sites.txt
```

**Проверка одного URL:**
```bash
python -m src.main --url https://example.com
```

**Интерактивный режим** (без аргументов):
```bash
python -m src.main
```

### Аргументы командной строки

| Аргумент | Описание | Требуется для |
|----------|----------|---------------|
| `--batch <файл>` | Путь к файлу со списком URL (по одному на строку) | Аудит сайтов |
| `--url <URL>` | Проверить один URL | Аудит сайтов |
| `--source <источник>` | Источник данных: `yandex_maps` или `2gis` | Сбор лидов |
| `--query <запрос>` | Поисковый запрос (например, "стоматология") | Сбор лидов |
| `--city <город>` | Город для поиска (например, "Казань") | Сбор лидов |
| `--limit <число>` | Максимальное количество результатов | Сбор лидов |
| `--output <файл>` | Переопределить путь к CSV-экспорту (опционально) | Все режимы |
| `--no-sqlite` | Отключить экспорт в SQLite | Все режимы |

### Выходные данные

#### При сборе лидов
При использовании `--source` вывод показывает:
- Количество найденных лидов
- Детали каждого лида (название, категория, адрес, телефон, сайт, ссылка на карточку)
- Предупреждения о квотах API

#### При аудите сайтов
Результаты сохраняются в `data/out/audit_results.csv` со следующими колонками:
- `business_name` — название бизнеса
- `website` — исходный URL
- `final_url` — финальный URL после редиректов
- `site_status` — статус: alive/dead/error
- `http_status` — HTTP код ответа
- `is_reachable` — доступен ли сайт
- `has_https` — используется HTTPS
- `title` — заголовок страницы
- `h1` — первый заголовок H1
- `has_viewport` — наличие viewport meta-тега
- `form_count` — количество форм
- `text_length` — длина текста в символах
- `has_phone_link` — найден ли телефон
- `has_whatsapp_link` — найден ли WhatsApp
- `has_telegram_link` — найден ли Telegram
- `technical_score` — технический балл (0-100)
- `outdated_score` — балл устаревания (0-100)
- `lead_priority` — приоритет лида (0-100)
- `page_quality` — качество: strong/average/weak
- `lead_label` — метка: ignore/review/target/hot
- `notes` — примечания
- `error_message` — сообщение об ошибке (если есть)

#### База данных SQLite
При включенном SQLite (`--sqlite`, по умолчанию) данные сохраняются в `data/out/audit_database.sqlite` с двумя таблицами:
- `businesses` — собранные лиды
- `audits` — результаты аудита

## Конфигурация

### Настройки по умолчанию

Конфигурация находится в `config/settings.py`:

```python
class Settings:
    # Настройки браузера/сканера
    HEADLESS = True                    # Запуск в headless-режиме
    TIMEOUT_MS = 15000                 # Таймаут запроса (мс)
    USER_AGENT = "Mozilla/5.0 ..."     # User-Agent
    
    # Настройки источников
    YANDEX_MAPS_ENABLED = False        # Включить Яндекс Карты
    TWOGIS_ENABLED = False             # Включить 2GIS
    YANDEX_MAPS_API_KEY = ""           # API ключ Яндекс
    
    # Файлы экспорта
    DEFAULT_CSV_OUT = Path("data/out/audit_results.csv")
    DEFAULT_SQLITE_OUT = Path("data/out/audit_database.sqlite")
    
    # Паузы между запросами
    MIN_PAUSE_SEC = 2.0                # Минимальная пауза
    MAX_PAUSE_SEC = 5.0                # Максимальная пауза
```

Создайте файл `.env` в корне проекта:

| Переменная | Описание | По умолчанию | Обязательная |
|------------|----------|--------------|--------------|
| `YANDEX_MAPS_API_KEY` | API ключ для Яндекс Карты | - | Да (для yandex_maps) |
| `YANDEX_MAPS_ENABLED` | Включить парсер Яндекс | `false` | Нет |
| `TWOGIS_ENABLED` | Включить парсер 2GIS | `false` | Нет |

```bash

```

## Компоненты

### SiteChecker (`src/analyzers/site_checker.py`)
- Проверяет доступность сайта
- Получает HTML-контент
- Обрабатывает редиректы
- Определяет HTTPS-статус
- Обрабатывает SSL-ошибки (возвращает статус "error")

**Ключевые методы:**
- `fetch_html(url: str) -> Tuple[SiteCheck, Optional[str]]` — основной метод

### HtmlAnalyzer (`src/analyzers/html_analyzer.py`)
- Парсит HTML с помощью BeautifulSoup (lxml)
- Извлекает: title, h1, viewport meta-тег, meta description
- Считает количество форм и изображений
- Подсчитывает длину текста
- Обнаруживает телефоны, WhatsApp, Telegram ссылки

**Ключевые методы:**
- `analyze(html: str) -> HtmlAnalysis` — основной метод

### Scorer (`src/scoring/scorer.py`)
Вычисляет три типа оценок:
1. **Technical score** (0-100) — на основе доступности, HTTPS, HTML валидности, viewport, форм
2. **Outdated score** (0-100) — на основе эстетических признаков (устаревшие паттерны)
3. **Lead priority** (0-100) — взвешенная сумма: `tech * 0.4 + old * 0.3 + content * 0.3`

**Классификация качества:**
- `strong`: tech >= 80 и old <= 20
- `average`: 50 <= tech < 80 или 20 < old <= 40
- `weak`: tech < 50 или old > 40

**Метки лидов:**
- `ignore`: priority < 40
- `review`: 40 <= priority < 55
- `target`: 55 <= priority < 75
- `hot`: priority >= 75

### CsvExporter (`src/exporters/csv_exporter.py`)
- Сохраняет список `AuditRecord` в CSV
- Использует кодировку UTF-8 с BOM для совместимости с Excel
- Создает директорию вывода при необходимости
- Поддерживает режим добавления (`append=True`)

**Ключевые методы:**
- `export(records: List[AuditRecord], append: bool = True)` — экспорт в CSV

### SQLiteExporter (`src/exporters/sqlite_exporter.py`)
- Сохраняет бизнес-лиды и результаты аудита в SQLite
- Создает таблицы `businesses` и `audits` с автоматическим созданием
- Поддерживает индексацию по URL и источнику

**Ключевые методы:**
- `export_leads(businesses: List[BusinessRecord])` — экспорт лидов
- `export_audits(audits: List[AuditRecord])` — экспорт аудитов

### YandexParser (`src/parsers/yandex_parser.py`)
- Парсит Яндекс Карты API v1
- Автоматически формирует поисковый запрос (query + city)
- Извлекает: название, категорию, адрес, телефон, сайт, URL карточки
- Обрабатывает ошибки API (403 квота, невалидный ключ)
- Возвращает пустой список при ошибках для корректной работы пайплайна

**Ключевые методы:**
- `search(query: str, city: str, limit: int = 20) -> List[BusinessRecord]` — основной метод

**Обработка ошибок:**
- 403 + "Limit is exceeded" → понятное сообщение о квоте
- Сохраняет диагностику: URL запроса, статус, тело ответа

### TwoGISParser (`src/parsers/twogis_parser.py`)
- Парсит 2GIS API
- Извлекает контакты организаций
- Возвращает `BusinessRecord` с данными

**Ключевые методы:**
- `search(query: str, city: str, limit: int = 20) -> List[BusinessRecord]` — основной метод

### LeadCollector (`src/services/lead_collector.py`)
- Фасад для сбора лидов из различных источников
- Динамически загружает парсеры
- Возвращает единый список `BusinessRecord`

**Ключевые методы:**
- `collect(source: str, query: str, city: str, limit: int = 20) -> List[BusinessRecord]`

### AuditPipeline (`src/pipelines/audit_pipeline.py`)
- Оркестрирует процесс аудита
- Отображает прогресс-бар с помощью tqdm
- Обрабатывает исключения для отдельных URL
- Поддерживает настраиваемую задержку между запросами

**Ключевые методы:**
- `run(urls: List[str], delay: float = 0.5) -> List[AuditRecord]` — запуск пайплайна

## Устранение неполадок

### Ошибка: "YANDEX_MAPS_API_KEY не настроен"
**Проблема:** Не указан API ключ для Яндекс Карт.

**Решение:** Добавьте в `.env`:
```bash
YANDEX_MAPS_API_KEY=ваш_ключ
YANDEX_MAPS_ENABLED=true
```

### Ошибка: "Limit is exceeded" (403)
**Проблема:** Превышена квота запросов к Яндекс API.

**Решение:** 
- Проверьте баланс и лимиты на [Яндекс.Разработчик](https://developer.tech.yandex.ru/)
- Увеличьте паузы между запросами через `MIN_PAUSE_SEC` и `MAX_PAUSE_SEC`
- Дождитесь сброса квоты (обычно сутки)

### SSL certificate verify failed
**Проблема:** Ошибка при проверке сайтов с самоподписанными сертификатами.

**Решение:** Ошибка корректно обрабатывается, сайт получает статус `error`. Проверьте, что httpx установлен с поддержкой SSL. При необходимости отключите проверку SSL в настройках (не рекомендуется для продакшена).

### Модули не найдены
**Проблема:** `ModuleNotFoundError` при импорте.

**Решение:** Убедитесь, что вы запускаете из корня проекта:
```bash
cd site-audit-v1
python -m src.main --batch data/sites.txt
```

### tqdm не отображается
**Проблема:** Прогресс-бар не появляется в консоли.

**Решение:** Установите tqdm:
```bash
pip install tqdm
```

### CSV не создается
**Проблема:** Файл `audit_results.csv` не создается.

**Решение:** Проверьте права на запись в директорию `data/out/`. Приложение автоматически создает директорию при необходимости.

### Ошибки парсинга HTML
**Проблема:** BeautifulSoup не может распарсить HTML.

**Решение:** Убедитесь, что установлен lxml:
```bash
pip install lxml beautifulsoup4
```

### Пустые результаты при сборе лидов
**Проблема:** Парсеры возвращают пустой список.

**Решение:**
- Проверьте API ключ и квоты
- Увеличьте `limit` (возможно, запрос слишком ограничивающий)
- Проверьте правильность названия города (используйте официальные названия)
- Проверьте сетевые подключения и доступность API

# CLAUDE.md

Контекст для AI-агентов (Claude Code, Codex CLI, Cursor и т.д.).
Этот файл читается при старте сессии — держим его коротким.

## Что за проект

**KURSOR PARSER** — SaaS-система автоматической генерации сайтов
для салонов красоты. Пайплайн:
Google Places (Радар) → Яндекс.Карты (обогащение) → Аудит → Парсинг
блоков → LLM-курация → Сборка JSON-конфига → Деплой через neuralsync.

UI — Streamlit-дашборд (`ui/admin_dashboard.py`).

## Жёсткие правила

1. **Секреты — только через `.env`**, никогда не хардкодить.
2. **Перед задачей — `git status`**. Не работаем на грязном дереве.
3. **Conventional commits**: `refactor:`, `feat:`, `chore:`, `docs:`.
4. **При rename файлов — `git mv`**, чтобы git распознал.
5. **Внутри проекта — прямой импорт**, не subprocess.

## Кто ты и что тебе можно

Если ты **Claude Code в VS Code** или **Codex CLI** — у тебя есть
права на запуск команд и редактирование файлов. Действуй сам.

Если ты **Claude Desktop** (отдельная программа, через MCP) —
**ты пишешь только промпты и архитектуру**. Код выполняет Codex.
Это разделение экономит токены и предотвращает конфликты.
